Multiline Shrinkwrap

CSS max-width on chat bubbles wastes space — the bubble stretches to max-width even when the last line is short. Pretext's walkLineRanges() binary-searches for the tightest width that keeps the same line count. This "shrinkwrap" has never existed on the web before.
